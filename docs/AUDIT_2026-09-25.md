## P2 — À planifier

- **`maplibre-gl` 4.7 → 6.x** (GHSA-jrc7-96c5-q579, contournement de `DOM.sanitize()`). Le risque réel est faible : les deux popups qui utilisent `setHTML` (`hazards.js`, `agentTracking.js`) échappent déjà toutes les données. Mais la montée de version est majeure (4 → 6) et doit être validée sur un appareil réel (carte, clusters, 3D, tuiles hors-ligne). Le bundle `maplibregl` pèse 780 Ko, c'est aussi le moment d'en mesurer l'impact.
- **La vague P0 « identité visuelle » du 31/08 n'est pas sur `main`** : on trouve encore l'emoji 🗺️ comme logo (favicon, `.login-badge` dans `appShell.js`, `.brand-mark` dans `appView.js`, `public/icon-*.svg`). Ce travail (logo vectoriel pin or/vert forêt, icônes SVG) n'a jamais été poussé ; il est à refaire ou à récupérer.
- **`appView.js` fait 2 873 lignes**, soit environ 20 % du code : c'est le principal point de dette technique. Pistes de découpage : administration (villes, invitations, agents), rapports, tournée, IA.
- Styles inline dans les gabarits HTML de `appView.js` (tournée, stats, aperçu d'image) : ils ignorent le mode sombre, à migrer vers des classes CSS.
- Le toast « CensGo est prêt à fonctionner hors connexion » s'affiche aussi par-dessus l'écran « Impossible de démarrer », ce qui est contradictoire. Il est aussi trop étroit sur mobile (4 lignes).
- `console.log` de performance laissés dans `dataLoader.js` et `main.js` : à faire passer par `core/debug.js`.
- Dépendances à jour de version mineure possibles : `@supabase/supabase-js` 2.117, `vite` 8.3, `dexie` 4.4.6. Pas de couverture de code (`@vitest/coverage-v8` absent).
- Branches distantes obsolètes à supprimer : `claude/audit-setup-fwfdc8`, `claude/audit-setup-6o85fz`, `fix/census-points-navigation-instrumentation-…` (déjà constatées comme sans valeur lors des audits d'août).

## Points solides

- Échappement HTML systématique (`escapeHtml`) sur toutes les données utilisateur injectées dans le DOM.
- CSP stricte (`script-src 'self'`, sans `unsafe-inline` ni `unsafe-eval`), et le bouton « Réessayer » n'utilise plus de `onclick` inline.
- Photos dans un bucket privé, consultées uniquement par URL signée de 5 minutes.
- Fonction Edge IA : contrôle d'origine, session et rôle, et limites de taille sur le texte, les points et les images.
- CI GitHub Actions : actions épinglées par SHA, lint, tests puis build avant le déploiement Pages.
- Bonnes bases d'UX terrain : `lang="fr"`, cibles tactiles ≥ 44 px, champs tous étiquetés, `safe-area`, `reduced-motion`.
